# 工作顺序（请在心里完成，不要输出推理过程）

1. 先看画面：主体是什么、处于什么形态、在做什么、有没有人、有没有文字。
2. 判断 base material（基础物料），例如“苹果”“香蕉”“红薯”。
   - 只写物料本体，**不要**带“干/片/粉/条/丝”等产品后缀；
     例如画面是苹果片/苹果干，material 都写“苹果”。
3. 判断 material_form（形态）。
4. 判断 material_state（所处生命周期状态）。这是**画面事实**：
   - 新鲜切好的果片 → fresh 或 prepared
   - 正在烘干/受热干燥中 → drying
   - 已完全干燥的成品 → dried 或 finished
   - 无法判断 → unknown
   **不允许**因为任务意图是“苹果干”就写 dried；必须看画面。
5. 判断 process_stage（工序）。不确定时用 other，不要硬猜成某个具体工序。
6. 判断设备、场景、景别、运镜。
7. 判断人物与字幕情况。
8. 最后逐项打分（见评分规则），overall 由你自己的判断得出。

# 分类规则

* material_form：整颗/整块=whole；切片=slice；切块=piece；条/丝=strip；
  粉末=powder；颗粒=granule；叶片=leaf；看不到决定不了=unknown。
* material_state 只描述物料本身的干湿进程，不描述工序。
* process_stage 描述画面处于哪一步：铺盘=tray_arrangement，进烘房/装料=loading，
  烘房内受热=inside_dryer，出料=unloading，成品=finished_product，包装=packaging，
  只有设备=equipment，只有厂房空镜=factory，判断不了=other。
* 设备：画面里真的出现烘干设备时才填 equipment_type 且 equipment_visible=true；
  只是听到/提到设备则 equipment_visible=false，equipment_type 可为 null。
* description：一句话描述**这一段画面可见的证据**，必须来自你看到的帧，
  换一段不同的素材就要写出不同的话（不要套用固定句式）。
  提到主体、动作、人物有无、镜头运动等具体信息，长度 15-60 字。

# 评分规则（0.0-1.0）

每个分数独立评估，不要给所有片段同一组分数。含义大致为：

* 0.20 差：几乎不可用（主体基本看不清 / 画面糊 / 抖动严重 / 字幕遮挡主体）
* 0.50 勉强：可用但明显有瑕疵（主体偏小或偏暗 / 字幕偏多 / 构图杂乱）
* 0.80 良好：正常可用（主体清楚、画面稳定、字幕不影响主体）
* 0.95 优秀：素材级（主体清晰居中、光线好、运镜稳、无干扰）

字段含义：
* material_relevance: 画面与“基础物料本身”的相关度（不是与任务意图的相关度）
* visual_quality: 清晰度、曝光、噪点等画质
* subtitle_cleanliness: 1.0 表示无字幕/水印干扰，越低表示字幕越多越花
* stability: 抖动与运动模糊程度，越稳越高
* composition: 构图是否适合直接当素材使用
* overall: 你对“这段素材能否直接用于自动混剪”的综合判断（可低于各项平均）

subtitle_score: 0.0-1.0，字幕/贴纸对画面的干扰程度（0 表示完全没有）。
